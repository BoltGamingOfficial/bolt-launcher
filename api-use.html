Bolt Launcher has not received approval or an API key, and the integration is not live. This page explains the intended use; it is not a claim of partnership or endorsement.

1. What Bolt Launcher is building

Bolt Launcher is an independent Minecraft launcher being developed in Rust as a free, non-commercial hobby project. There is no business model, and there are currently no plans for advertisements, subscriptions, paid features, or other monetisation.

I started the project because I wanted one launcher experience for Minecraft Java and Bedrock, and a less tedious way to install mods. The mod manager is meant to make content easier to find and install in the context of a specific Minecraft instance.

Intended user flow: a player selects an instance, searches the CurseForge catalogue from inside Bolt Launcher, checks compatible projects and files for that instance's Minecraft version and mod loader, then chooses Install to Instance. If the project and file are available for third-party distribution and Overwolf has approved the integration, Bolt will use the permitted download flow and place the downloaded file into the selected instance's appropriate folder. The goal is to avoid the browser visit, manual download step and file moving.

Bolt Launcher will not host mod files on its own servers, mirror or re-upload CurseForge files, modify downloaded projects, or run a creator-upload website. The user asks for an installation and the file is obtained through the provider-authorised delivery flow. We understand that this can still count as third-party distribution under CurseForge's rules, even though Bolt is not a file host. We also understand that a launcher with built-in discovery and installation overlaps with some CurseForge app features, so we have asked Overwolf to confirm whether this particular use is allowed.

2. Intended request behaviour

  • Requests will be initiated by a user searching, browsing, opening a project, or requesting an install — not by continuous background crawling.
  • Search and file queries will be limited to what is needed for the selected game, version and loader. Pagination and request frequency will respect the provider's documented limits.
  • Project names, descriptions, authors, artwork and links will remain attributed to their source. Provider-hosted assets will not be copied into a Bolt-operated catalogue or re-hosted by Bolt.
  • Bolt Launcher will use the provider's documented download flow where approved. It will not mirror, proxy, repack, or independently redistribute provider files.
  • Projects or files marked unavailable, removed, restricted, or not permitted for third-party distribution will not be made installable. The launcher will not bypass bans, removals, access controls or author restrictions.
  • No provider API key will be committed to this public repository.

3. CurseForge approval and terms review

CurseForge API access is subject to an application reviewed by Overwolf and acceptance of its third-party API terms. CurseForge says the review considers the impact on authors' earnings, its servers/CDN, and how third-party distribution obtains author consent.

Before enabling CurseForge access, Bolt Launcher will obtain approval for the actual native-desktop use case and follow the current API documentation and terms. The published third-party API terms include restrictions on saving or caching API-derived data, disclosing an API key, and using API materials to build a product or service that competes directly or indirectly with CurseForge.

Bolt Launcher does not plan to earn money from CurseForge downloads, and it is not a business. We are not planning to pay authors directly; this is a free hobby project. We will give creators attribution, link to their original project pages, and respect the Project Distribution Toggle and all file availability rules. We understand that downloads through third-party services may not count toward the author's normal download totals or Reward Program earnings under CurseForge's current guidance, and we will not claim otherwise.

CurseForge announced API-key authentication for direct CDN downloads for launchers, modpack installers and similar tools. We understand that this is a technical requirement for eligible integrations, not automatic approval of any particular application. We will follow the instructions and any additional requirements Overwolf gives us.

Questions requiring written confirmation before launch: (1) whether the exact in-launcher browse-and-install workflow described above is permitted under the non-competition restriction; (2) what is allowed for transient display of project metadata and thumbnails under the no-save/no-cache clause; (3) how a non-transferable API key may be used by a distributed desktop launcher; and (4) how the author distribution toggle and 2026 download-source attribution work together for creator analytics and rewards. Bolt Launcher will not assume these points are permitted or work around the restrictions.

The application has been submitted and is awaiting a decision. Until access is approved and the outstanding terms questions are answered, the CurseForge integration will remain disabled. No API key is published in this website or public repository.

4. Modrinth and other providers

Any Modrinth or future provider integration will be implemented separately and only in accordance with that provider's current API rules, attribution requirements, content distribution permissions and rate limits. Approval from one provider does not imply approval from another.

5. Creator rights and trademarks

Mods, resource packs, project names, descriptions, logos and artwork belong to their respective authors or rights holders. Bolt Launcher does not claim ownership of third-party content. Users will be directed to the original project pages and applicable creator and provider terms.

Minecraft is a trademark of Microsoft. CurseForge is a product of Overwolf. Modrinth is an independent platform. Bolt Launcher is not affiliated with, endorsed by, or sponsored by these organisations.

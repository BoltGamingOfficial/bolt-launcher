Privacy notice

A clear explanation of what this project website does — and what this page does not yet cover.

Last updated: 31 October 2026
Scope: This notice covers the static Bolt Launcher project website hosted through GitHub Pages. It is not yet the complete privacy notice for the downloadable Bolt Launcher application.

1. About this website

This website provides project information and links to the public Bolt Launcher GitHub repository. It does not provide a Bolt Launcher account, sign-in form, comment system, newsletter, payment form or direct file upload.

2. Information submitted through this website

The project website does not intentionally ask visitors to submit personal information. It does not include project-operated advertising pixels, analytics scripts, behavioural profiling, or a contact form.

When you follow links to GitHub or another third-party service, that service handles your visit under its own terms and privacy notice. The site is hosted by GitHub Pages; GitHub may process technical information such as request and security logs as part of operating its hosting service. See GitHub's Privacy Statement.

3. The desktop launcher

Bolt Launcher is still in pre-release development. The desktop application may communicate with third-party services needed for Minecraft account authentication, game services, content discovery, and downloads. Those services process requests under their own policies.

A complete application privacy notice will be published before a public release. It will explain, in detail, what account/session information is stored locally, where it is stored, which network services are contacted, how optional diagnostics work (if any), and how users can remove local data. This website notice should not be treated as a substitute for that application notice.

4. Children

This project website is not designed to collect personal information from children. No visitor account or user-submission feature is provided here.

5. Changes

This notice may be updated as the project website or application changes. The date at the top will be updated when this page is materially revised.

6. Contact

For website privacy questions, use the GitHub repository contact / issue page. Do not post passwords, Microsoft account details, access tokens, API keys, or other sensitive personal information in a public issue.

Built around the player

A launcher should make playing easier.

Less friction between choosing a setup and getting into the game. More clarity about what belongs to each instance.

01 / INSTANCES

Keep every setup organised

Manage separate game versions and configurations rather than turning one folder into a mess.

02 / DISCOVERY

Find the right content

Version-aware mod and resource-pack discovery, with project artwork, is part of the roadmap. Provider access and author permissions come first.

03 / EDITIONS

Java and Bedrock

The goal is a unified launcher experience, including reliable Bedrock installation detection and a manual installation selector.

04 / PERFORMANCE

Lightweight by design

Built in Rust with a focus on keeping launcher overhead low and avoiding unnecessary background activity.

05 / CONTROL

Your installs, your choice

Clear installation locations and instance-level choices are central to the product direction.

06 / EXPERIENCE

Ad-free direction

Bolt Launcher is being designed as a focused utility, not an advertising surface.

Early development, openly stated.
